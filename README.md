# Naqeeb Arshad - Mechanical Design Engineer Portfolio
Static, responsive GitHub Pages portfolio built with HTML5, CSS3 and vanilla JavaScript.

## Structure
- `index.html` - portfolio content and SEO metadata
- `style.css` - responsive premium engineering visual system
- `script.js` - 4-project pagination, project modals, navigation, reveal animations and mobile menu
- `assets/profile.jpg` - professional profile photo
- `assets/portfolio.pdf` - original full PDF portfolio
- `assets/projects/` - project imagery extracted from the supplied portfolio

## GitHub Pages
Upload all files/folders to the repository root. In **Settings > Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then save. The project-site URL will be `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.

## Updating
Edit text in `index.html` or the `projects` array in `script.js`. Replace an image while keeping its filename, or update its relative path in `script.js`. Commit changes; GitHub Pages redeploys automatically.
