# Naqeeb Arshad - Mechanical Design Engineer Portfolio

Static, responsive personal portfolio built with HTML5, CSS3 and vanilla JavaScript. No npm, build process, backend or database is required.

## Repository structure

- `index.html` - website content and SEO/Open Graph metadata
- `style.css` - responsive dark engineering visual system
- `script.js` - mobile menu, project cards/modals, reveal animations, active navigation and back-to-top
- `assets/profile.jpg` - professional profile photo
- `assets/portfolio.pdf` - full original portfolio PDF
- `assets/projects/` - CAD renders, analysis images and project visuals

## Run locally

Open `index.html` directly in a browser. For the closest GitHub Pages behavior, serve the folder with any simple static server, but no server is required for deployment.

## Publish on GitHub Pages

1. Sign in to GitHub and create a new public repository, for example `naqeeb-portfolio`.
2. Upload the complete contents of this folder to the repository root. Keep the `assets` folder structure unchanged.
3. Commit the files to the `main` branch.
4. Open the repository's **Settings > Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.
7. After GitHub finishes deployment, the site URL will normally be `https://YOUR-GITHUB-USERNAME.github.io/naqeeb-portfolio/`.
8. If the repository itself is named `YOUR-GITHUB-USERNAME.github.io`, the URL will normally be `https://YOUR-GITHUB-USERNAME.github.io/`.

## Updating later

Edit `index.html` for text/sections, `style.css` for appearance, and `script.js` for project data/interaction. Replace an image while keeping the same filename to update it without changing code. Replace `assets/portfolio.pdf` whenever the full PDF portfolio is updated. Commit and push changes; GitHub Pages will redeploy automatically.

## Content source

Website text, project names, technical results, experience, education, certifications, achievements and contact information are based on the supplied Mechanical Design Portfolio. Unsupported claims have intentionally not been added.
