# Naqeeb Arshad - Mechanical Design Portfolio

Static GitHub Pages portfolio rebuilt from the supplied 17-page PDF.

## Upload structure
- `index.html`, `style.css`, `script.js`, `README.md` stay in repository root.
- `assets/profile.jpg` is the single profile image.
- `assets/portfolio.pdf` is the supplied portfolio PDF.
- `assets/projects/` contains every unique non-profile image extracted from the PDF exactly once.

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

The Projects section uses 4 large cards per pagination page. The AFSD project is explicitly labelled FINAL YEAR PROJECT (FYP).
